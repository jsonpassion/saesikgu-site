# 새식구 사이트

iOS 앱 새식구(Kinwise, 亲戚通, 義実家ノート 등)의 소개 페이지, 개인정보 처리방침, 이용약관, 문의. 10개 언어.

이 저장소의 HTML은 **손으로 고치지 않는다**. 앱 저장소의 `Tools/site/build.py`가 `Docs/legal`, 스토어 문구, 스크린샷에서 만든다.

```bash
cd ../familyTree && python3 Tools/site/build.py
```

`main`에 푸시하면 GitHub Pages가 배포한다: https://jsonpassion.github.io/saesikgu-site/
